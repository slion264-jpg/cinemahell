## 변경
- 추천작 카드의 평론 지표·짧은 평가·출처를 복원했습니다. 추천 근거/방송 발언/긴 설명 블록은 복원하지 않았습니다.
- 평론 고정 스냅샷(확인 2026-11-15): 세크리터리 RT78%·150평론, 미스 리틀 선샤인 RT91%·215평론, 호루몽 씨네21 전문가7.00/10·4명. RT는 긍정 평론 비율이며 평균점수가 아닙니다. 씨네21 전문가 평균과 구분합니다. 카드마다 원문 링크와 확인일을 표시합니다.
- 포스터·제목·카드 일반 영역을 클릭하면 기존 운영 규칙과 같은 Google 검색 결과를 새 탭으로 엽니다. `searchUrl`이 있으면 그 값을 사용하고, 아니면 제목+(제작연도)+검색 접미사(기본 영화)를 URL 인코딩합니다. 실제 anchor라 키보드·모바일 접근 가능하며 window.open 팝업은 없습니다.
- 평론 점수·출처는 각 원문으로 별도 이동합니다. 링크/버튼 중첩이나 카드 click 핸들러가 없어 제거/저장/원문 클릭이 Google 검색을 열지 않습니다.
- **카드 하단 왼쪽 X=제거, 오른쪽 책갈피=보고 싶은 것 저장/취소.** 포스터 위가 아닙니다. 28×28 버튼,14×14 아이콘. 61px 고정 하단 영역과 늘어나는 본문으로 같은 줄 카드의 버튼 정렬을 유지합니다. 제목/평론 줄바꿈이 하단 정렬을 깨지 않도록 합니다.
- X는 본 것 표시를 하지 않습니다. 제거는 홈/마이 카드에서 숨기며 페이지 하단의 일시적인 실행 취소로 마지막 제거를 복원할 수 있습니다. 기존 본 것/보고 싶은 것 기록 자체를 삭제하지 않습니다.
- 마이 시네마는 본 것/보고 싶은 것 두 목록 유지. 저장한 작품에 대해 마이 화면 별도 ‘본 것으로 이동’/‘본 것 표시 취소’ 관리 버튼을 제공합니다. 카드의 X와 섞지 않습니다.
- 탐색은 변경 없이 기존 서비스 연결. 모든 시안 상태는 메모리 한정이며 새로고침 시 초기화, 실제 계정/저장 키 미접근.
