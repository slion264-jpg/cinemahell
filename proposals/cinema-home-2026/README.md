## 이번 변경
- 홈: 영웅 영역·소개 카피·뽑기 제거. 최신 방송일과 추천 작품 카드만 표시. 2~6편에 대응하는 반응형 그리드, 실제 원본 최신 방송은 3편이며 임의 작품으로 채우지 않습니다. 6편 초과는 앞 6편으로 제한하는 제안입니다.
- 모든 현재 작품의 상세: 방송 추천 사실/직접 발언 상태, 외부 평론, 과거 추천 이력을 명확히 구분. 방송 발언은 미확인으로 표기.
- 탐색: 기존 운영 화면을 새 탭으로 여는 명시적인 진입 화면. 축소 복제나 가짜 탐색은 제공하지 않습니다. 기존 추천자·연도·장르·플랫폼·기타 필터/계정은 운영 사이트 그대로입니다.
- 마이 시네마: **본 것 / 보고 싶은 것** 두 목록. 카드에서 표시하고 목록 사이로 이동·삭제할 수 있습니다. 시안 메모리만 사용하며 새로고침하면 초기화됩니다. 기존 계정/책갈피/제외/개인 `cinemaEdits`를 읽거나 쓰지 않습니다. 실제 앱 통합은 별도 승인 단계입니다.
