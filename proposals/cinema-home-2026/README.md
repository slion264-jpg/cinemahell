## 제안 방향
- 대형 아카이브 대신 한 편을 발견하는 홈. 차콜·라임 색상, 절제된 편집 디자인.
- 최신 방송의 추천자를 먼저 보여주고, 방송일과 추천 이력을 작품 상세로 연결.
- 같은 작품(정확한 제목+제작연도)은 하나, 여러 추천 방송 기록은 각각 보존.
- 가장 최근 방송의 작품이 모두 제외되면 그 사실을 안내하고 이전 방송으로 몰래 대체하지 않음.
- 탐색·마이 시네마는 **제안 흐름**이며 전체 탐색/기존 책갈피는 운영 사이트 링크로 계속 접근.
- 시안의 저장/제외는 현재 열린 페이지 메모리에만 남고 새로고침하면 초기화. 기존 계정, `cinemaEdits`, 책갈피, 제외 키를 읽거나 변경하지 않음. 실제 앱 연동 시 기존 계정 범위/필터 기본값 보존 필요.
