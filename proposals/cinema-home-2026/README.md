# 시네마지옥 디자인 제안 03

검토용 별도 브랜치 `proposal/cinema-home-2026-11` / Draft PR #2. 운영 미적용, 승인 전 merge/deploy 금지.

## 열기
`preview.html` 다운로드 후 브라우저로 엽니다. 이미지 내장 단일 파일로 서버/로그인 불필요. 포스터/제목을 클릭하면 작품 상세, 메뉴는 홈/탐색/마이 시네마입니다. 상세 해시 주소 공유 시 HTML 파일도 함께 전달해야 하며 운영 도메인의 새 페이지가 아닙니다.

## 이번 변경
- 추천 근거·평론 확인 링크와 관련 블록, 외부 평가 점수·요약·출처 데이터를 시안에서 제거했습니다. 작품명/연도/추천자/방송일만 간결하게 남깁니다.
- 긴 텍스트 버튼 대신 포스터 우측 상단에 **X + 책갈피**를 고정했습니다. X가 왼쪽, 책갈피가 오른쪽이며 둘 다 기존 운영 목록 스타일의 28×28 버튼/14×14 아이콘/5px 간격입니다. 제목 줄바꿈과 분리된 절대 위치여서 캡션 높이가 아이콘 위치에 영향을 주지 않습니다.
- 이 시안의 X는 **본 것 표시/취소**, 책갈피는 **보고 싶은 것 저장/취소**입니다. 선택 상태는 금색이며 title/aria-label/aria-pressed로 의미를 제공합니다. 둘 중 하나를 선택하면 다른 목록에서는 빠집니다.
- **운영 서비스의 X는 여전히 제외 기능입니다. 시안 의미를 운영 동작에 적용하지 않았습니다.** 두 의미의 차이는 최종 통합 전에 다시 확인해야 합니다.
- 마이 시네마의 본 것/보고 싶은 것 카드와 작품 상세에도 같은 고정 아이콘을 사용합니다. 아이콘을 다시 누르면 해제, 다른 아이콘을 누르면 목록 이동됩니다.
- 홈은 최신 추천작 목록만, 2~6편 그리드. 현재 원본 최신 방송은 2026-11-13의 3편이며 다른 날짜/가상 작품으로 채우지 않습니다.
- 탐색은 기존 운영 탐색을 새 탭으로 여는 그대로의 연결입니다. 원래 탐색 구현/계정/필터는 수정하지 않았습니다.

## 데이터/저장
운영 canonical RAW_DATA at a435b416, 개인 cinemaEdits 이전 스냅샷을 사용합니다. 시안 저장은 현재 페이지 메모리 한정이고 새로고침하면 초기화됩니다. 실제 계정/책갈피/제외/개인 저장소를 읽거나 쓰지 않습니다. 포스터는 기존 운영 공개 TMDB 캐시 자료입니다.

## 검사
`node --test proposals/cinema-home-2026/test.cjs` → 10/10 통과. 2~6편, 긴 제목, 고정 아이콘 구조/크기/순서, 버튼과 링크의 비중첩, 접근성 상태, 두 목록 이동/해제, 탐색 연결, 평론 제거, 운영 상태 비침범을 검사합니다.

실제 Chromium 렌더링은 이 실행환경에서 시작 실패했습니다. 실제 스크린샷·시각/모바일 실기기 QA는 미완료이며 코드/VM 검사를 실제 렌더 검증으로 표현하지 않습니다. 병합 전 390px/1440px의 텍스트·터치·겹침 검토가 필요합니다.

변경은 이 제안 폴더만. 운영 파일·워크플로·보안·배포 설정 변경 없음.
